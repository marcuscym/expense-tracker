# Expense Tracker

A local, private, mobile-first expense tracker. Single `index.html` file — HTML, CSS, and
vanilla JavaScript, no dependencies, no build step.

- Add / edit / delete expenses (amount, category, date, description)
- Monthly budget summary with a progress ring
- Editable per-category budgets with progress bars
- Month switcher to view past months
- All data is stored in your browser via `localStorage` — nothing is sent anywhere

## Use it

Open `index.html` in a browser, or visit the GitHub Pages URL and
**Add to Home Screen** on your phone. Your data stays on that device.
